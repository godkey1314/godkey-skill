# 迭代变更（动态工作区）

> 本目录是整个项目的**动态工作区**，按**功能/需求**组织一体化工作包，**用文件夹本身显式表达状态**。

## 四态状态机

```text
01-待确认/  ──确认方案──▶  02-进行中/  ──同步静态文档 + 门禁通过──▶  99-已归档/
                              │  ▲
                     实验暂停  │  │ 恢复开发
                              ▼  │
                           03-已搁置/
```

- **`01-待确认/`**：方案已起草等待拍板，尚未进入大规模施工；
- **`02-进行中/`**：当前活跃迭代，开新会话只需看此目录即可恢复上下文；
- **`03-已搁置/`**：中途暂停的实验或暂缓需求，显式移出视线但保留现场与搁置原因；
- **`99-已归档/`**：已完成、通过测试与审查、**已同步静态真相文档**的历史包（必须通过 `godkey_gate.py archive` 门禁迁入）。

## 功能包结构（`YYYY-MM-DD_功能名/`）

- `01-方案.md`：背景目标、蓝图对齐、代码摸底、分层方案、影响分析与测试要点
- `02-进展.md`：跨会话持续更新的迭代记录、关键决策、变更前快照与静态文档同步清单
- `03-测试.md`：测试计划 + 测试报告
- `04-审查.md`：自检循环与代码审查报告
- `ops/`：本次迭代专属迁移 SQL、一次性数据修复脚本、上线配置与回滚步骤

## 小修（Hotfix）

单文件、局部根因明确、不改变蓝图与架构的小 Bug 修复不建独立功能包，直接追加到 `hotfix记录.md`（推荐运行 `godkey_gate.py hotfix`）。
