# 迭代变更（动态工作区）

> 本目录以**功能/需求**为单位管理动态迭代，**文件夹本身即状态**，不在文档正文手写状态文字。

## 状态流转

```text
01-待确认/  ──确认方案──▶  02-进行中/  ──同步静态文档 + 门禁通过──▶  99-已归档/
                              │  ▲
                         实验暂停 │  │ 恢复开发
                              ▼  │
                           03-已搁置/
```

## 标准功能包内容

- `01-方案.md`：背景目标、蓝图对齐、代码摸底、分层方案与测试要点
- `02-进展.md`：跨会话持续记录的进展、决策、变更前快照与静态文档同步清单
- `03-测试.md`：测试计划 + 测试报告
- `04-审查.md`：自检循环与代码审查报告
- `ops/`：本次迭代专属迁移 SQL、一次性清洗脚本、上线配置与回滚步骤

## 小修（Hotfix）

单文件、局部根因明确的小 Bug 修复（不涉及架构/设计变更）无需新建功能包目录，直接记录到本目录的 `hotfix记录.md`。
