# eval-2：Bug 小修复（Hotfix 路径）

## 前置条件

- 一个已有 `full` 或 `lite` 文档体系并纳入 Git 管理的项目；
- 存在一个单文件、局部根因明确的小 Bug（如某导出函数未对 `None` 判空导致异常）。

## 用户指令

> 运行导出命令的时候遇到空值报错了，帮我排查修一下

## 期望行为检查表

- [ ] 第一步运行 `godkey_gate.py audit` 并读取 `references/开发流程.md`
- [ ] **Pass 0**：读取项目规范与相关蓝图，不直接凭报错行猜代码
- [ ] **Pass 1**：追到报错函数定义处及调用方完整读清，确认仅涉单文件、不改架构/蓝图 → **据此判定走 Hotfix 路径**
- [ ] **不新建**独立功能包目录（不把单文件小修过度重型化）
- [ ] 修复前先写出能复现原 Bug 的测试（或复现验证），修复后跑通回归测试
- [ ] 收尾运行 `godkey_gate.py hotfix ...` 记入 `hotfix记录.md`，并运行 `godkey_gate.py check-sync --mode hotfix --project-root <项目根>` 贴出 `PASS` 输出

## 反例警报（出现即不通过）

- ❌ 未读代码查根因就硬套“不许读代码”卡死，或未经排查直接瞎猜修一行
- ❌ 为单文件 5 行小修强行建完整功能包
- ❌ 改完代码未在 `hotfix记录.md` 留痕，或未运行 `check-sync`
