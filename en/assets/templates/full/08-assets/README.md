# Assets

> Static asset directory for OpenAPI exports, architecture diagrams, wireframes, and screenshots.

## Recommended Layout

```text
08-assets/
├── api/          # OpenAPI / Swagger exports
├── images/       # Architecture diagrams, flowcharts, screenshots
└── other/        # External reference materials
```

## Conventions

- Use lowercase filenames with hyphens or underscores (no spaces);
- Compress images (recommended `< 2MB`) to keep Git history lean.
