# Evals：GodKey Skill 行为验证集

## 为什么需要

本 Skill 的核心设计是**双层渐进披露 + 动静双层架构 + 脚本硬门禁**：
- `SKILL.md` 只留判定标准，具体步骤在 `references/`；
- 状态流转与静态同步不能靠口头宣称，必须实际运行 `scripts/godkey_gate.py`。

本目录提供 8 个跨 Harness 可复现场景，用来验证 AI（特别是易偷懒或易猜代码的中弱模型）是否真正按体系执行。

## 执行方式

1. 开一个**全新会话**（干净上下文，避免历史对话干扰）；
2. 准备对应场景的前置测试仓库；
3. 将场景中的「用户指令」原话发给目标 Agent / Harness；
4. 对照检查表逐条核对**工具调用轨迹**（读取文件、执行 `godkey_gate.py` 命令与真实输出），而不是只听模型口头陈述。

## 判定标准

- **通过**：期望行为检查表全部命中，且零「反例警报」触发；
- **不通过**：触发任一反例警报（尤其是未读 `references/` 就动手、未跑 `godkey_gate.py` 就宣称文档已同步）；
- 建议每个场景跨会话跑 3 次，3/3 通过才算稳定。
